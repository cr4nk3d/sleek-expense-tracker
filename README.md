# Sleek Expense Tracker

Live Demo: https://cr4nk3d.github.io/sleek-expense-tracker/

## 💡 Overview
A clean and simple web app to track your personal finances — add, view, and manage expenses in a sleek interface. The tracker helps you visualise spending and stay on top of your budget.

## 🧠 Technologies
Built with:
- HTML  
- CSS  
- JavaScript

## 🚀 Quick Start
1. Clone the repo:  
   `git clone https://github.com/cr4nk3d/sleek-expense-tracker.git`  
2. Open `index.html` in your browser  
3. Start adding your expenses!

## 📝 Usage
- Enter a description, amount and category  
- Save to see totals update
